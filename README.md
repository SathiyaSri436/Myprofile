## 💻 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/SathiyaSri436/PersonalProfile.git
   ```

2. Open the project folder:

   ```bash
   cd PersonalProfile
   ```

3. Open `index.html` in your web browser.

4. Alternatively, use the **Live Server** extension in Visual Studio Code to run the website locally.

## 🌍 Deploy on GitHub Pages

1. Push your project files to a GitHub repository.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Click **Save**.
7. Wait for deployment to complete.

Your website will be available at:

`https://SathiyaSri436.github.io/PersonalProfile/`

Replace `PersonalProfile` with your actual repository name if it is different.
